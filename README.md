# Localit — Local Multi-Shop Delivery Platform

Localit is a modern full-stack local commerce marketplace connecting local neighborhood stores with nearby consumers. Unlike warehouse-centric quick-commerce systems, Localit empowers independent brick-and-mortar merchants to control their own inventories, hours, and prices while delivering an ultra-fast shopping experience to customers.

## Tech Stack
- **Frontend**: React 18, Vite, React Router v6, Tailwind CSS, Lucide Icons, Axios
- **Backend**: Node.js, Express.js, Prisma ORM, JSON Web Tokens (JWT), Bcrypt
- **Database**: PostgreSQL (Structured relational schema with constraints, indexes & atomic ACID transactions)
- **Payments**: Pluggable Payment Abstraction (Mock Payment Gateway & Cash on Delivery)
